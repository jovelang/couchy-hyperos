# 隐私、权限和公开整理

## 仓库不包含什么

不包含个人姓名/昵称配置、家庭设备地址和 SSID、精确位置、米家设备 ID/实体、账号令牌、连接码、签名密钥、安装 APK、电视截图、媒体缓存、播放源、日志或聊天记录。公开 Git 历史从整理后的源码开始；`.gitignore` 排除本地配置和运行目录，发布前检查额外扫描工作树。

仓库所有者的公开 GitHub 用户名、上游作者和项目来源是公开归属信息，按归属保留；不得为“脱敏”删除原作者版权或许可证。

## 功能打开后处理的数据

- 桌面配置、应用顺序和隐藏项保存在设备本地 DataStore。昵称、天气城市和网页凭据默认不预填。
- 壁纸和屏保本地缓存会占用存储；更换素材不会逐次把截图上传到云端。网络素材需由用户主动开启或选择，受服务可用性和权利条款限制。
- 天气需要用户输入城市；相关站点/坐标随天气请求发给中国天气网或 Open-Meteo。没有默认住宅坐标，不自动根据 IP 或定位权限填城市。
- Wi-Fi 名称读取可能需要 Android 的位置权限，这是系统权限关联；不表示天气自动获取定位。
- 可选辅助服务用于遥控按键；不自动开启，不向远端收集屏幕阅读内容。
- 可选 ADB 保持只维护所有者已授权的开关，默认关闭，不自动接受新主机，不保持电视永不休眠。
- 网页服务器能看到电视状态、前台应用、截图、文件与配置。其登录会话、任务和临时下载只保存在用户主机，HA 令牌不交给浏览器。

## 提交问题之前

优先提交复现步骤、型号和固件版本、错误标签；删掉 ADB serial / IP、设备 ID、账号、SSID、连接码和授权头。截图先检查时钟旁昵称、网络菜单、文件列表和远程设置页。不要上传完整配置、原始账号日志或全部已安装应用清单。

`scripts/check_public_tree.py` 是发布辅助，不等于能发现一切敏感信息；合并前仍需人工审查变更和二进制资源。任何测试数据必须用虚构值，真实测试记录留在本机忽略目录。
